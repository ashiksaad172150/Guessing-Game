
# 🎯 Guess My Number Game

A simple number guessing game built using **HTML**, **CSS**, and **JavaScript**.

---
[🔗Live Website: ](https://ashiksaad172150.github.io/Guessing-Game/)


---
## 🕹️ How to Play

- The computer picks a **random number between 1 and 20**.
- Your goal is to guess it correctly.
- After each guess:
  - You'll get feedback (Too high / Too low / Correct).
  - Your score decreases if the guess is wrong.
  - You can reset and play again using the **"Again!"** button.

## 📂 Project Structure

guess-my-number/

## 💡 Features

- Responsive retro-style UI
- Random number generation
- Dynamic DOM updates
- Score and highscore tracking

## 🚀 Technologies Used

- HTML5
- CSS3
- Vanilla JavaScript (ES6)

## 🛠️ Setup

1. Clone the repo:
   ```bash
   git clone https://github.com/your-username/guess-my-number.git
   ```
